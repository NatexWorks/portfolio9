## Verification limits

- Reference timings, easing curves, scroll lengths, breakpoints and source technologies were not reverse-engineered or assumed.
- Some references were partially inaccessible in automated inspection; those limits are stated above.
- The new site borrows interaction principles, not reference branding, copy, assets or exact compositions.
- Mobile adaptations and accessibility safeguards are NatexWorks implementation recommendations, not claims about reference-site behaviour.
